# CogniVeil - Early Dementia Detection System

## Overview
CogniVeil is a machine learning-based dementia detection system designed to assist in the early identification of dementia using cognitive assessment data.

## Features
- Cognitive assessment analysis
- Machine learning predictions
- Interactive user interface
- Data visualization and score interpretation

## Tech Stack
- Python
- Machine Learning
- Scikit-learn
- Flask
- Streamlit
- HTML
- CSS
- JavaScript
